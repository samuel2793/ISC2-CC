# Profundizacion en Network Access Control (NAC)

En su forma mas simple, network access control o NAC es una forma de impedir que dispositivos no deseados se conecten a una red. Algunos sistemas NAC permiten instalar software requerido en el dispositivo del usuario final para hacer cumplir la conformidad del dispositivo con la politica antes de conectarse.

Un ejemplo de alto nivel de un sistema NAC es el acceso a internet en un hotel. Normalmente, un usuario que se conecta a la red del hotel debe aceptar la politica de uso aceptable antes de que se le permita acceder a internet. Despues de que el usuario hace clic en el boton de aceptacion, el dispositivo se conecta a la red que habilita el acceso a internet. Algunos hoteles agregan una capa adicional que requiere que el huesped introduzca una contrasena especial o un numero de habitacion y nombre de huesped antes de conceder el acceso. Esto previene abusos por parte de alguien que no es huesped del hotel y puede incluso ayudar a rastrear abuso de red hasta un usuario particular.

Un escenario ligeramente mas complejo es una empresa que separa los dispositivos BYOD de empleados de los dispositivos propiedad de la corporacion en la red. Si el dispositivo BYOD esta preaprobado y se permite conectarlo a la red corporativa, el sistema NAC puede validar el dispositivo usando una direccion de hardware o software instalado, e incluso comprobar que el software antivirus y el sistema operativo esten actualizados antes de conectarlo a la red. Alternativamente, si es un dispositivo personal al que no se permite conectarse a la red corporativa, puede redirigirse a la red de invitados para acceso a internet sin acceso a recursos corporativos internos.
