# Profundizacion en centros de datos on-premises

Primero, consideramos los requisitos de aire acondicionado de un centro de datos. Los servidores y otros equipos generan mucho calor, que debe gestionarse adecuadamente. Esto no es solo para que sea comodo cuando hay humanos presentes, sino para asegurar que el equipo se mantenga dentro de sus parametros operativos. Cuando el equipo se calienta demasiado, puede fallar mas rapido o invalidar la garantia. La mayoria de los equipos esta programada para apagarse automaticamente cuando se alcanza cierto umbral de temperatura. Esto ayuda a proteger el equipo, pero un sistema apagado no esta disponible para los usuarios. Un apagado anormal del sistema tambien puede provocar perdida o corrupcion de datos.

Otra consideracion para el centro de datos on-premises son los sistemas de supresion de incendios. En Estados Unidos, la mayoria de los edificios comerciales deben tener sistemas de rociadores que se activan en caso de incendio. Estos rociadores minimizan la cantidad de dano causado al edificio e impiden que el fuego se propague a areas adyacentes, pero pueden ser perjudiciales para el equipo electronico, ya que el agua y la electricidad no se mezclan. La mayoria de los sistemas de supresion de incendios basados en agua no funcionan como en las peliculas, donde un incendio en una parte del edificio activa los rociadores de todo el edificio.

Otro peligro es tener agua por encima en un centro de datos. Con el tiempo, las tuberias de agua fallaran y pueden gotear sobre el equipo. Este riesgo puede reducirse en cierta medida usando un sistema de tuberia seca que mantiene el agua fuera de las tuberias sobre el centro de datos. Estos sistemas tienen una valvula fuera del centro de datos que solo se abre cuando un sensor indica que hay un incendio. Como el agua no se mantiene en las tuberias sobre el centro de datos, se reduce el riesgo de fugas.
