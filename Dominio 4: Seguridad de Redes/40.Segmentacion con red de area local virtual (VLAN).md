# Segmentacion con Virtual Local Area Network (VLAN)

Las VLAN son separaciones virtuales dentro de un switch y se usan principalmente para limitar el trafico de broadcast. Una VLAN puede configurarse para comunicarse con otras VLAN o no, y puede usarse para segregar segmentos de red.

Hay algunos usos comunes de VLANs en redes corporativas. El primero es separar telefonos de voz sobre IP (VoIP) de la red corporativa. Esto se hace con mayor frecuencia para gestionar de forma mas eficaz el trafico de red generado por comunicaciones de voz, aislandolo del resto de la red.

Otro uso comun de VLANs en una red corporativa es separar el centro de datos de todo el resto del trafico de red. Esto facilita mantener el trafico servidor-a-servidor contenido en la red del centro de datos, al tiempo que permite que cierto trafico desde estaciones de trabajo o desde la web acceda a los servidores, como se trato brevemente antes.

Las VLANs tambien pueden usarse para segmentar redes. Por ejemplo, una VLAN puede separar las estaciones de trabajo de nomina del resto de las estaciones de trabajo de la red. Tambien pueden usarse reglas de enrutamiento para permitir que solo los dispositivos dentro de esta VLAN de nomina accedan a los servidores que contienen informacion de nomina.

Antes tambien tratamos network access control (NAC). Estos sistemas usan VLANs para controlar si los dispositivos se conectan a la red corporativa o a una red de invitados. Aunque un controlador de acceso inalambrico pueda conectarse a un solo puerto en un switch fisico de red, la VLAN asociada con la conexion del dispositivo en el controlador de acceso inalambrico determina la VLAN en la que opera el dispositivo y a que redes se le permite conectarse.

Finalmente, en grandes redes corporativas, las VLANs pueden usarse para limitar la cantidad de trafico de broadcast dentro de una red. Esto es mas comun en redes de mas de 1000 dispositivos y puede separarse por departamento, ubicacion, edificio o cualquier otro criterio segun sea necesario. Lo mas importante que debe recordarse es que, aunque las VLANs estan separadas logicamente, puede permitirse que accedan a otras VLANs; tambien pueden configurarse para denegar acceso a otras VLANs.
