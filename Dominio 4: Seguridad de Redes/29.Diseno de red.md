# Diseno de red

**El objetivo del diseno de red es satisfacer los requisitos de comunicacion de datos y lograr un rendimiento general eficiente.**

### Segmentacion de red

La segmentacion de red implica controlar el trafico entre dispositivos conectados en red. La segmentacion de red completa o fisica ocurre cuando una red se aisla de todas las comunicaciones externas, de modo que las transacciones solo pueden ocurrir entre dispositivos dentro de la red segmentada.

![imagen](img/24.jpg)

### Demilitarized Zone (DMZ)

Una DMZ es un area de red disenada para ser accedida por visitantes externos, pero que sigue estando aislada de la red privada de la organizacion. La DMZ a menudo aloja servidores publicos web, de correo electronico, archivos y otros recursos.

![imagen](img/25.jpg)

### Virtual Local Area Network (VLAN)

Las VLAN son creadas por switches para segmentar logicamente una red sin alterar su topologia fisica.

![imagen](img/26.jpg)

### Virtual Private Network (VPN)

Una virtual private network (VPN), o red privada virtual, es un tunel de comunicacion que proporciona transmision punto a punto tanto de autenticacion como de trafico de datos sobre una red no confiable.

![imagen](img/27.jpg)

### Defensa en profundidad

La defensa en profundidad usa multiples tipos de controles de acceso en capas literales o teoricas para ayudar a una organizacion a evitar una postura de seguridad monolitica.

![imagen](img/28.jpg)

### Network Access Control (NAC)

Network access control (NAC), o control de acceso a la red, es un concepto de control de acceso a un entorno mediante el cumplimiento estricto y la implementacion de la politica de seguridad.

![imagen](img/29.jpg)
