# Red privada virtual (VPN)

**Una virtual private network (VPN), o red privada virtual, no es necesariamente un tunel cifrado. Es simplemente una conexion punto a punto entre dos hosts que les permite comunicarse.**

Por supuesto, la VPN puede proporcionar comunicaciones seguras, pero solo si los protocolos de seguridad se han seleccionado y configurado correctamente para proporcionar una ruta confiable sobre una red no confiable, como internet.

Los usuarios remotos emplean VPNs para acceder a la red de su organizacion y, dependiendo de la implementacion de la VPN, pueden tener disponibles la mayoria de los mismos recursos que si estuvieran fisicamente en la oficina. Como alternativa a costosas conexiones dedicadas punto a punto, las organizaciones usan VPNs gateway-to-gateway para transmitir informacion de forma segura por internet entre sitios o incluso con socios de negocio.
