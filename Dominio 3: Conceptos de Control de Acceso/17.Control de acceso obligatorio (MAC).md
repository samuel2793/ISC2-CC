# Control de acceso obligatorio (MAC)

Una politica de **mandatory access control (MAC)**, o control de acceso obligatorio, es aquella que se aplica uniformemente a todos los sujetos y objetos dentro del limite de un sistema de informacion. En terminos simples, esto significa que solo los administradores de seguridad debidamente designados, como sujetos confiables, pueden modificar cualquiera de las reglas de seguridad establecidas para sujetos y objetos dentro del sistema. Esto tambien significa que, para todos los sujetos definidos por la organizacion (es decir, conocidos por su sistema integrado de gestion de identidades y control de acceso), la organizacion asigna un subconjunto de privilegios totales para un subconjunto de objetos, de modo que se impide al sujeto realizar cualquiera de las siguientes acciones:
- Pasar la informacion a sujetos u objetos no autorizados
- Conceder sus privilegios a otros sujetos
- Cambiar uno o mas atributos de seguridad en sujetos, objetos, el sistema de informacion o componentes del sistema
- Elegir los atributos de seguridad que se asociaran con objetos recien creados o modificados
- Cambiar las reglas que gobiernan el control de acceso

**Aunque MAC suena muy similar a DAC, la diferencia principal es quien puede controlar el acceso. Con control de acceso obligatorio (MAC), es obligatorio que los administradores de seguridad asignen derechos de acceso o permisos; con control de acceso discrecional (DAC), queda a discrecion del propietario del objeto.**
