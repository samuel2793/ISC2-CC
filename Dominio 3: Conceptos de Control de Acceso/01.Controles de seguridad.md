# Controles de seguridad

### Que es un control de seguridad?
**Un control es una salvaguarda o contramedida disenada para preservar la confidencialidad, integridad y disponibilidad de los datos. Esto, por supuesto, es la Triada CIA.**

El control de acceso implica limitar que objetos pueden estar disponibles para que sujetos, de acuerdo con que reglas.

Un ejemplo breve de control es un firewall, que se incluye en un sistema o red para impedir que algo del exterior entre y perturbe o comprometa el entorno. El firewall tambien puede impedir que la informacion interna salga a la Web, donde podria ser vista o accedida por personas no autorizadas.
