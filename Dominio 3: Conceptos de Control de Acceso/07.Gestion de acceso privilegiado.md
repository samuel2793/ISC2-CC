# Gestion de acceso privilegiado

**La gestion de acceso privilegiado proporciona el primer caso de uso y quizas el mas familiar. Considera una identidad de usuario humano a la que se le conceden varios privilegios de crear, leer, actualizar y eliminar en una base de datos.**

Sin gestion de acceso privilegiado, el control de acceso del sistema tendria esos privilegios asignados al usuario administrativo de forma estatica, efectivamente "activados" las 24 horas del dia, todos los dias. La seguridad dependeria del proceso de inicio de sesion para evitar el uso indebido de esa identidad. En cambio, la gestion de acceso privilegiado just-in-time incluye subconjuntos especificos de privilegios basados en roles que solo se activan en tiempo real cuando la identidad solicita usar un recurso o servicio.

### Este escenario ilustra por que la gestion de acceso privilegiado es importante:
ABC, Inc. tiene un departamento de TI pequeno responsable del aprovisionamiento de usuarios y la administracion de sistemas. Para ahorrar tiempo, los empleados del departamento de TI agregaron sus ID al grupo Domain Admins, dandoles efectivamente acceso a todo dentro del entorno de servidores y estaciones de trabajo Windows. Mientras revisaban una factura recibida por correo electronico, abrieron un mensaje con un adjunto malicioso que inicio un ataque de ransomware.

Como estaban usando privilegios de Domain Admin, el ransomware pudo cifrar todos los archivos en todos los servidores y estaciones de trabajo. Una solucion de gestion de acceso privilegiado podria limitar el dano causado por este ransomware si los privilegios de administrador se usan solo al realizar una funcion que requiere ese nivel de acceso. Las operaciones rutinarias, como las tareas diarias de correo electronico, se realizan sin un nivel de acceso superior.
