# Controles y riesgos

**Un control sirve para reducir el riesgo de acuerdo con el lugar que ocupa dentro de la tolerancia al riesgo de la persona u organizacion.**

- Un control fisico seria un cinturon de seguridad.
- Un control administrativo seria una ley que exige el uso del cinturon de seguridad.
Estos controles, juntos, sirven para reducir el riesgo de conducir hasta un grado aceptable para el conductor y para la sociedad.

Otro ejemplo no tecnico es el de una estanteria alta. Debido a que existe el riesgo de que una estanteria alta se vuelque y posiblemente hiera a alguien, los codigos o regulaciones locales de construccion podrian exigir que las estanterias se aseguren a una pared usando una correa o soporte.

En este caso, el riesgo es la lesion a personas. Un control administrativo es el codigo de construccion, y la fijacion real de la estanteria a la pared es el control fisico. Tanto los controles administrativos como los fisicos trabajan juntos para mitigar el riesgo.
