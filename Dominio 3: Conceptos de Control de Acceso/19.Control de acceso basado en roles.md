# Control de acceso basado en roles

Se crea un rol y se le asigna el acceso requerido para el personal que trabaja en ese rol. Cuando un usuario asume un puesto, el administrador lo asigna al rol apropiado. Si un usuario deja ese rol, el administrador elimina a ese usuario y entonces se elimina el acceso de ese usuario asociado con ese rol. RBAC funciona bien en un entorno con alta rotacion de personal y multiples personas con requisitos de acceso similares.
