# Metodos de autenticacion

Hay dos tipos de autenticacion. Usar solo uno de los metodos de autenticacion indicados anteriormente se conoce como **single-factor authentication (SFA)**, o autenticacion de un solo factor.

Conceder acceso a los usuarios solo despues de demostrar o presentar correctamente dos o mas de estos metodos se conoce como **multi-factor authentication (MFA)**, o autenticacion multifactor.

#### Autenticacion de un solo factor:
Uso de solo uno de los tres factores disponibles (algo que sabes, algo que tienes, algo que eres) para realizar el proceso de autenticacion solicitado.

#### Autenticacion multifactor:
Uso de dos o mas instancias distintas de los tres factores de autenticacion (algo que sabes, algo que tienes, algo que eres) para la verificacion de identidad.

Una buena practica comun es implementar al menos dos de las tres tecnicas comunes de autenticacion:
- Basada en conocimiento
- Basada en token
- Basada en caracteristicas

La autenticacion basada en conocimiento utiliza una frase de contrasena o un codigo secreto para diferenciar entre un usuario autorizado y uno no autorizado. Si has seleccionado un numero de identificacion personal (PIN), creado una contrasena o introducido algun otro valor secreto que solo tu conoces, entonces has experimentado autenticacion basada en conocimiento.

El problema de usar este tipo de autenticacion por si sola es que suele ser vulnerable a diversos ataques. Por ejemplo, el servicio de soporte podria recibir una llamada para restablecer la contrasena de un usuario. El reto es asegurar que la contrasena se restablezca solo para el usuario correcto y no para otra persona que se haga pasar por ese usuario. Para una mejor seguridad, se requeriria una segunda o tercera forma de autenticacion basada en un token o en una caracteristica antes de restablecer la contrasena. El uso combinado de un ID de usuario y una contrasena consiste en dos cosas que se saben y, como no cumple el requisito de usar dos o mas de los metodos de autenticacion indicados, no se considera MFA.
