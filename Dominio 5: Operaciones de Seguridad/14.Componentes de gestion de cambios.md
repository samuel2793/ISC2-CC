# Componentes de gestion de cambios

![imagen](img/9.jpg)

**El proceso de gestion de cambios incluye los siguientes componentes.**

### Documentacion

Todas las practicas principales de gestion de cambios abordan un conjunto comun de actividades centrales que comienzan con una solicitud de cambio (RFC) y avanzan por varias etapas de desarrollo y prueba hasta que el cambio se libera a los usuarios finales. De principio a fin, cada paso esta sujeto a alguna forma de gestion formalizada y toma de decisiones; cada paso produce registros contables o entradas de log para documentar sus resultados.

### Aprobacion

Estos procesos normalmente incluyen: evaluar las RFC para verificar que esten completas, asignarlas al proceso adecuado de autorizacion de cambios segun el riesgo y las practicas organizativas, revisar con las partes interesadas, identificar y asignar recursos, aprobar o rechazar segun corresponda, y documentar la aprobacion o el rechazo.

### Rollback

Segun la naturaleza del cambio, puede ser necesario completar una variedad de actividades. Estas suelen incluir: programar el cambio, probarlo, verificar los procedimientos de rollback, implementar el cambio, evaluarlo para confirmar una operacion correcta y efectiva, y documentarlo en el entorno de produccion.

La autoridad para rollback generalmente estaria definida en el plan de rollback, que podria ser inmediato o programarse como un cambio posterior si el monitoreo del cambio sugiere un rendimiento inadecuado.
