# Redes

**Una red es simplemente dos o mas computadoras enlazadas entre si para compartir datos, informacion o recursos.**

Para establecer correctamente comunicaciones de datos seguras, es importante explorar todas las tecnologias involucradas en las comunicaciones entre computadoras.

Desde hardware y software hasta protocolos, cifrado y mas, hay muchos detalles, estandares y procedimientos que conviene conocer.

## Tipos de redes

### Hay dos tipos basicos de redes:

- **Local area network (LAN)**

Una red de area local (LAN) es una red que normalmente abarca un solo piso o edificio. Comunmente corresponde a un area geografica limitada.

- **Wide area network (WAN)**

Wide area network (WAN), o red de area amplia, es el termino que normalmente se asigna a las conexiones de larga distancia entre redes geograficamente remotas.

## Dispositivos de red

**Hubs**

Los hubs se usan para conectar multiples dispositivos en una red. Es menos probable verlos en redes empresariales o corporativas que en redes domesticas. Los hubs son dispositivos cableados y no son tan inteligentes como los switches o routers.

**Switch**

En lugar de usar un hub, podrias considerar usar un switch, tambien conocido como hub inteligente. Los switches son dispositivos cableados que conocen las direcciones de los dispositivos conectados a ellos y enrutan el trafico hacia ese puerto/dispositivo en lugar de retransmitirlo a todos los dispositivos.

Al ofrecer mayor eficiencia en la entrega de trafico y mejorar el rendimiento general de los datos, los switches son mas inteligentes que los hubs, pero no tan inteligentes como los routers. Los switches tambien pueden crear dominios de broadcast separados cuando se usan para crear VLANs.

**Router**

Los routers se usan para controlar el flujo de trafico en las redes y a menudo se usan para conectar redes similares y controlar el flujo de trafico entre ellas. Los routers pueden ser cableados o inalambricos y pueden conectar multiples switches. Mas inteligentes que hubs y switches, los routers determinan la "ruta" mas eficiente para que el trafico fluya a traves de la red.

**Firewall**

Los firewalls son herramientas esenciales para gestionar y controlar el trafico de red y proteger la red. Un firewall es un dispositivo de red usado para filtrar trafico. Normalmente se despliega entre una red privada e internet, pero tambien puede desplegarse entre departamentos (redes segmentadas) dentro de una organizacion (red general). Los firewalls filtran el trafico basandose en un conjunto definido de reglas, tambien llamadas filtros o listas de control de acceso.

**Servidor**

Un servidor es una computadora que proporciona informacion a otras computadoras en una red. Algunos servidores comunes son servidores web, servidores de correo electronico, servidores de impresion, servidores de bases de datos y servidores de archivos. Todos estos, por diseno, estan conectados en red y son accedidos de alguna manera por una computadora cliente. Los servidores suelen protegerse de forma diferente a las estaciones de trabajo para proteger la informacion que contienen.

**Endpoint**

Los endpoints son los extremos de un enlace de comunicacion de red. Un extremo suele estar en un servidor donde reside un recurso, y el otro extremo suele ser un cliente que solicita usar un recurso de red. Un endpoint puede ser otro servidor, una estacion de trabajo de escritorio, laptop, tablet, telefono movil o cualquier otro dispositivo de usuario final.

## Otros terminos de redes

**Ethernet**

Ethernet (IEEE 802.3) es un estandar que define conexiones cableadas de dispositivos en red.

Este estandar define la forma en que los datos se formatean sobre el cable para asegurar que dispositivos diferentes puedan comunicarse sobre los mismos cables.

### Direccion del dispositivo

**Direccion Media Access Control (MAC)**

A cada dispositivo de red se le asigna una direccion Media Access Control (MAC). Un ejemplo es 00-13-02-1F-58-F5. Los primeros 3 bytes (24 bits) de la direccion indican el proveedor o fabricante de la interfaz fisica de red. Dos dispositivos no pueden tener la misma direccion MAC en la misma red local; de lo contrario, ocurre un conflicto de direccion.

**Direccion Internet Protocol (IP)**

Aunque las direcciones MAC generalmente se asignan en el firmware de la interfaz, los hosts IP asocian esa direccion con una direccion logica unica. Esta direccion IP logica representa la interfaz de red dentro de la red y puede ser util para mantener comunicaciones cuando un dispositivo fisico se reemplaza por hardware nuevo. Algunos ejemplos son 192.168.1.1 y 2001:db8::ffff:0:1.
