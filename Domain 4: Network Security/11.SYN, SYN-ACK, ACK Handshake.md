# Handshake SYN, SYN-ACK, ACK

Entre el cliente y el servidor existe un sistema para sincronizar y reconocer cualquier solicitud, conocido como handshake de tres vias. Este handshake se usa para establecer una conexion TCP entre dos dispositivos.

Aqui veremos de forma simplificada como se establecen las comunicaciones con un servidor web. Dependiendo del protocolo exacto, puede haber negociacion adicional de conexion. Primero, el cliente envia un paquete de sincronizacion SYN al servidor web, puerto 80 o 443. Esta es una solicitud para establecer una conexion. El servidor web responde al paquete SYN con un reconocimiento conocido como SYN-ACK. Finalmente, el cliente reconoce la conexion con un ACK. En este punto, la conexion basica queda establecida y el cliente y el host negociaran comunicaciones seguras sobre esa conexion.
