# Computacion en la nube

**La computacion en la nube normalmente se asocia con un conjunto de recursos de computo basados en internet, y generalmente se vende como un servicio proporcionado por un cloud service provider (CSP), o proveedor de servicios en la nube.**

La computacion en la nube es similar a la red electrica. Se aprovisiona en una ubicacion geografica y se abastece usando un medio electrico que no necesariamente es obvio para el consumidor. Sin embargo, cuando quieres electricidad, esta disponible mediante una interfaz comun estandar y pagas solo por lo que usas.

La computacion en la nube es escalable, elastica y facil de usar para el aprovisionamiento y despliegue de servicios de Information Technology (IT).

Existen varias definiciones de que significa computacion en la nube segun estandares lideres, incluido NIST.

Esta definicion de NIST se usa comunmente en todo el mundo, citada por profesionales para aclarar que significa el termino "nube":

*"Un modelo para habilitar acceso ubicuo, conveniente y bajo demanda por red a un conjunto compartido de recursos de computo configurables (como redes, servidores, almacenamiento, aplicaciones y servicios) que pueden aprovisionarse y liberarse rapidamente con minimo esfuerzo de gestion o interaccion con el proveedor de servicios."*
NIST SP 800-145
